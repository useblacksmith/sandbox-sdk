# Blacksmith Sandbox SDKs

Client libraries for [Blacksmith](https://blacksmith.sh) sandboxes, one directory per language:

| Language   | Package                  | Path                  |
| ---------- | ------------------------ | --------------------- |
| TypeScript | `@useblacksmith/sandbox` | `packages/typescript` |

Each package has its own README with installation and a quickstart.

## Contributing

The TypeScript SDK is developed in [useblacksmith/web](https://github.com/useblacksmith/web) (`packages/sandbox-sdk`) and mirrored here by Copybara on every push to its `main`; `packages/typescript` in this repository is output. File issues here; code changes to the TypeScript SDK go to `useblacksmith/web`.
